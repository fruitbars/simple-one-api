## 零一万物接入simple-one-api

兼容OpenAI: 零一万物 API 与 OpenAI API 完全兼容，咱们直接可以在simple-one-api中配置。

```json
{
    "services": {
        "openai": [
            {
                "models": [
                    "yi-large",
                    "yi-spark",
                    "yi-medium",
                    "yi-medium-200k",
                    "yi-large-turbo"
                ],
                "enabled": true,
                "credentials": {
                    "api_key": "xxx"
                },
                "server_url": "https://api.lingyiwanwu.com/v1/chat/completions"
            }
        ]
    }
}
```
